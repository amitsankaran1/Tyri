Tyri 2.3 (8): Timed status, website saving and schedule error feedback.

- Timed blocks show “Unblocks at” in Focus and details. If Block now is also enabled, the timed end and continuing manual block are both explained.
- Type a website into a list and tap Save without pressing +. Reopen the list and confirm the website was saved.
- Paste an HTTP(S) URL containing a path, query or port: only its domain should be stored. Malformed addresses show an inline error and stay available to correct.
- If a schedule cannot register, Focus and details show a warning and Retry schedule. Settings are saved, but Save keeps the editor open to show the failure. Retry after resolving Screen Time access.
- Existing active-block restrictions, schedules, usage budgets and NFC settings should survive the upgrade.
- Live numeric usage totals remain unavailable. Physical Screen Time enforcement still needs on-device verification.

Please report the block type, its settings, and whether Tyri was open when an issue occurred.
